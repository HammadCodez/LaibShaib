## 🏛️ Project Overview
**LabShaib** is an institutional laboratory equipment scheduling, inventory tracking, and conflict prevention web application designed specifically for **NUST SEECS and engineering departments**.

It addresses the real-world friction students and lab engineers face:
* Preventing equipment hoarding and double-booking via algorithmic conflict detection.
* Enforcing a 4-hour academic single-session quota.
* Providing a 3-tier hierarchical role structure: **Super Admin** (institutional oversight), **Lab Instructor** (scoped to assigned laboratory room), and **Student** (equipment booking and digital voucher passes).
